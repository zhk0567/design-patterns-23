每模式 2～3 题，覆盖意图、区别、实战与坑。结合本仓库 `NN_*.py` 阅读。

## 创建型

### 01 Singleton 单例

**Q1.** 单例模式解决什么问题？Python 里有哪些实现方式？  
**A.** 保证类仅一个实例并提供全局访问。方式：`__new__` + 类变量、模块级对象、Borg 模式、`threading.Lock` 双重检查（见 `patterns/01_singleton.py`）。

**Q2.** 单例在多线程 Web 服务中有何风险？  
**A.** 非线程安全实现可能创建多个实例；且单例隐藏依赖、不利测试。应评估是否真需要全局唯一。

**Q3.** 单例 vs 静态类？  
**A.** 单例可延迟初始化、可继承（慎用）；静态类无实例状态管理灵活性。

### 02 Factory Method 工厂方法

**Q1.** 工厂方法与简单工厂（if/else 创建）区别？  
**A.** 工厂方法用子类决定实例化哪个产品，符合开闭原则；简单工厂常集中在一个函数里，新增类型要改该函数。

**Q2.** 何时用工厂方法？  
**A.** 创建逻辑会扩展、需把「创建」与「使用」解耦时，如多种 Logger（`patterns/02_factory_method.py`）。

### 03 Abstract Factory 抽象工厂

**Q1.** 抽象工厂与工厂方法的边界？  
**A.** 工厂方法创建**一种**产品；抽象工厂创建**一族**相关产品（如 Dark 主题按钮+输入框）。

**Q2.** 产品族很多时抽象工厂的问题？  
**A.** 接口膨胀，每增产品类型要改所有工厂实现。

### 04 Builder 建造者

**Q1.** Builder 与构造函数大量可选参数相比？  
**A.** Builder 分步清晰、易读，可保证构建顺序与合法性（`patterns/04_builder.py` HTTP 请求）。

**Q2.** 是否需要 Director？  
**A.** 构建步骤固定且多处复用时引入 Director；否则客户端直接调 Builder 即可。

### 05 Prototype 原型

**Q1.** 浅拷贝与深拷贝在原型模式中的影响？  
**A.** 浅拷贝共享嵌套可变对象；应用 `copy.deepcopy`（`patterns/05_prototype.py`）。

**Q2.** 何时用原型而非 `__init__`？  
**A.** 克隆成本高、配置复杂或需保留当前状态快照时。

## 结构型

### 06 Adapter 适配器

**Q1.** 适配器 vs 装饰器？  
**A.** 适配器改接口以兼容；装饰器同接口下增强行为。

**Q2.** 类适配器与对象适配器？  
**A.** 类适配器多重继承；对象适配器组合被适配对象（本仓库用法）。

### 07 Bridge 桥接

**Q1.** 桥接 vs 策略？  
**A.** 桥接分离抽象与实现两个维度；策略封装可替换算法，常由客户端选择。

**Q2.** 桥接解决什么问题？  
**A.** 避免笛卡尔积式子类爆炸（形状×渲染器）。

### 08 Composite 组合

**Q1.** 组合模式如何保证对叶子和容器使用一致？  
**A.** 统一组件接口；容器实现 add 并递归处理子节点（`patterns/08_composite.py`）。

**Q2.** 组合模式的代价？  
**A.** 难以限制「仅容器才有的操作」，需在接口或类型上约束。

### 09 Decorator 装饰器

**Q1.** GoF 装饰器与 Python `@decorator` 关系？  
**A.** 前者是结构型类组合；后者是语法糖包装函数，概念相关实现不同。

**Q2.** 装饰器顺序为何重要？  
**A.** 外层装饰先被调用链包裹，顺序影响最终行为（如先折扣后运费）。

### 10 Facade 外观

**Q1.** Facade 是否违反分层？  
**A.** 不必然；应为子系统提供简化入口，复杂规则不应全部堆在 Facade。

**Q2.** Facade 与 Mediator？  
**A.** Facade 单向简化调用；Mediator 协调多方互相通信。

### 11 Flyweight 享元

**Q1.** 享元的关键是什么？  
**A.** 内在状态可共享，外在状态由客户端传入（字符样式 vs 位置）。

**Q2.** 享元池何时失效？  
**A.** 池无界、键设计不当导致无法共享或内存泄漏。

### 12 Proxy 代理

**Q1.** 代理 vs 装饰器职责划分？  
**A.** 代理侧重访问控制、懒加载；装饰侧重叠加功能。实践中需按意图命名。

**Q2.** 虚拟代理要注意什么？  
**A.** 并发下避免重复创建真实对象；异步场景见 `demo_async()`。

## 行为型

### 13 Chain of Responsibility 责任链

**Q1.** 责任链与装饰器链区别？  
**A.** 责任链可能不处理请求并传递；装饰器通常增强并传递。

**Q2.** 动态责任链的价值？  
**A.** 运行时增删处理器，如审批流（`patterns/13_chain_of_responsibility.py` advanced）。

### 14 Command 命令

**Q1.** 命令模式如何支持撤销？  
**A.** 封装操作为对象，保存逆操作或快照，`undo()` 恢复（`patterns/14_command.py`）。

**Q2.** 异步命令队列场景？  
**A.** 命令入队后由 worker/async 执行，见 `demo_async()`。

### 15 Interpreter 解释器

**Q1.** 何时不该用解释器模式？  
**A.** 语法复杂、高频执行；应使用 AST、解析器生成器或编译。

**Q2.** 解释器与组合模式关系？  
**A.** 表达式树常由组合节点构成，interpret 递归求值。

### 16 Iterator 迭代器

**Q1.** Python 迭代器协议？  
**A.** `__iter__` 返回迭代器，`__next__` 直至 `StopIteration`。

**Q2.** 迭代时修改集合的问题？  
**A.** 可能跳过元素或异常；应迭代快照或禁止并发修改。

### 17 Mediator 中介者

**Q1.** 中介者模式的风险？  
**A.** 中介者演变为上帝对象，集中所有交互逻辑。

### 18 Memento 备忘录

**Q1.** 备忘录与 Command 撤销区别？  
**A.** 备忘录保存状态快照；Command 封装操作并可逆操作。

**Q2.** 备忘录的封装边界？  
**A.** 原发器生成/恢复，外部不应随意改 Memento 内部。

### 19 Observer 观察者

**Q1.** 观察者内存泄漏如何避免？  
**A.** 取消订阅、弱引用（`patterns/19_observer.py` WeakStockMarket）、生命周期绑定。

**Q2.** 观察者 vs 发布订阅（消息队列）？  
**A.** 观察者通常进程内同步/异步调用；Pub/Sub 常跨进程解耦。

### 20 State 状态

**Q1.** 状态模式 vs 策略模式？  
**A.** 状态在内部根据事件自动切换；策略常由客户端显式选择。

**Q2.** 状态类过多怎么办？  
**A.** 状态少可用 enum+转移表；复杂流程用状态机库。

### 21 Strategy 策略

**Q1.** 策略模式如何与 if/else 共存？  
**A.** 变体少时用 if；算法族扩展、需运行时切换时用策略。

### 22 Template Method 模板方法

**Q1.** 模板方法与策略区别？  
**A.** 模板方法用继承固定骨架；策略用组合替换步骤实现。

**Q2.** 钩子方法（hook）作用？  
**A.** 子类可选重写某些步骤，不必实现全部抽象步骤。

### 23 Visitor 访问者

**Q1.** 访问者模式的前提？  
**A.** 元素层次相对稳定，操作经常新增。

**Q2.** 双分派是什么？  
**A.** `accept(visitor)` 与 `visit_concrete_element` 共同决定调用哪个 visit 方法。

**Q3.** 新增元素类型的代价？  
**A.** 需修改所有 Visitor 子类，开闭原则在元素侧受损。
