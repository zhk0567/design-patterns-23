# 模式对比笔记

便于区分易混淆的设计模式（GoF 23）。

## 创建型

| 对比 | 工厂方法 | 抽象工厂 |
|------|----------|----------|
| 创建对象 | 一种产品，多种实现 | 一族相关产品（按钮+输入框） |
| 扩展点 | 新增具体产品 / 工厂子类 | 新增产品族（整套主题） |
| 示例文件 | `patterns/02_factory_method.py` | `patterns/03_abstract_factory.py` |

| 对比 | 建造者 | 原型 |
|------|--------|------|
| 关注点 | 分步组装复杂对象 | 通过克隆复制已有对象 |
| 典型场景 | HTTP 请求、SQL | 文档副本、配置快照 |

## 结构型

| 对比 | 适配器 | 装饰器 | 代理 |
|------|--------|--------|------|
| 目的 | 接口不兼容 → 能协作 | 动态叠加职责 | 控制访问（懒加载、权限） |
| 关系 | 包装旧接口 | 同接口增强 | 同接口代管 |
| 示例文件 | `patterns/06_adapter.py` | `patterns/09_decorator.py` | `patterns/12_proxy.py` |

| 对比 | 桥接 | 策略 |
|------|------|------|
| 维度 | 抽象与实现分离（形状×渲染） | 算法可替换（排序策略） |
| 结构 | 组合持有实现 | 组合持有策略对象 |
| 注意 | 减少继承维度 | 见行为型 `patterns/21_strategy.py` |

| 对比 | 组合 | 外观 |
|------|------|------|
| 树结构 | 统一叶子/容器接口 | 对多个子系统提供单一入口 |
| 示例 | 文件树 | 下单流程 |

## 行为型

| 对比 | 策略 | 状态 |
|------|------|------|
| 切换内容 | 算法族（客户端常主动选） | 对象内部状态驱动行为变化 |
| 谁决定 | 通常外部注入策略 | 状态对象在内部流转 |
| 示例文件 | `patterns/21_strategy.py` | `patterns/20_state.py` |

| 对比 | 观察者 | 中介者 |
|------|--------|--------|
| 通信 | 一对多广播 | 多方经中介间接通信 |
| 耦合 | 主题知道观察者列表 | 同事不直接引用彼此 |

| 对比 | 命令 | 备忘录 |
|------|------|--------|
| 封装 | 请求为对象（可撤销） | 对象内部状态快照 |
| 场景 | 撤销/重做、队列 | 编辑器存档 |

| 对比 | 模板方法 | 访问者 |
|------|----------|--------|
| 扩展 | 子类重写步骤 | 新增操作而不改元素类 |
| 骨架 | 父类固定流程 | 双分派遍历结构 |

## 与 Python 语法的关系

- **装饰器模式** ≠ `@decorator` 语法糖：前者是结构型 OOP 模式，后者是函数包装语法。
- **迭代器模式**：Python 内置 `__iter__` / `__next__`，见 `patterns/16_iterator.py` 与 [STDLIB_MAPPING.md](STDLIB_MAPPING.md)。
